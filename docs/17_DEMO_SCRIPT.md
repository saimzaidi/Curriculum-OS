# Five-Minute Demo Script

## 0:00–0:30 — Problem

“Schools plan the semester once, but real classrooms never follow the plan. Classes are cancelled, students miss prerequisites, and every lesson, quiz, and revision document drifts out of sync.”

## 0:30–1:10 — Source ingestion

Upload:

- Pakistani textbook chapter;
- past paper;
- eight-week calendar.

Show:

- detected chapters;
- page-grounded source blocks;
- one difficult page and its extracted structure.

## 1:10–1:50 — Curriculum graph and schedule

Show:

- concepts;
- prerequisites;
- textbook evidence;
- initial schedule;
- protected revision sessions.

Key line:

“The model understands the content. A constraint solver controls the calendar.”

## 1:50–2:30 — Generated teaching package

Open one lesson:

- objectives;
- timed plan;
- Karachi-localized example;
- three learner levels;
- homework;
- source references.

Open one authentic assessment.

Key line:

“The question is linked to what was actually taught and is designed to resist shallow copy-paste answers.”

## 2:30–3:25 — Classroom failure

Import a quiz CSV.

Show:

- 60% of class missed one concept;
- prerequisite chain;
- proposed 20-minute remediation block.

Approve it.

## 3:25–4:15 — Calendar disruption

Cancel two classes.

Run replan.

Show:

- locked practical preserved;
- remediation inserted;
- optional activity compressed;
- revision protected;
- before/after diff.

Key line:

“A dashboard reports failure. CurriculumOS changes tomorrow.”

## 4:15–4:45 — Offline survival

Export course pack.

Disable internet.

Open:

- schedule;
- lesson;
- notes;
- quiz;
- printable PDF.

## 4:45–5:00 — Closing

“CurriculumOS turns static books into a living teaching system—grounded in the school’s sources, adaptive to classroom reality, and usable even without reliable internet.”
