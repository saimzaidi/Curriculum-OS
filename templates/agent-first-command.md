# First Command to Give the Coding Agent

Read `AGENTS.md` and all files under `docs/` in numeric order.

Then:

1. summarize the product in ten lines;
2. identify any contradictions in the specifications;
3. propose the exact repository tree;
4. create Phase 0 only;
5. do not begin Phase 1;
6. run all tests;
7. report files changed, commands, test results, and remaining blockers.

The project must use:

- Next.js;
- FastAPI;
- PostgreSQL + pgvector;
- Prefect;
- OR-Tools;
- NetworkX;
- object-storage adapter;
- strict schemas.

Do not add agent frameworks, Neo4j, or extra product features.
